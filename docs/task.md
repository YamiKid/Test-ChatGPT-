# Описание задачи

Нужно было разработать небольшое нативное iOS-приложение — AI-чат в духе ChatGPT.

## Базовые требования

- Минимальная версия iOS — 18; поддержка iOS 18 и более новых версий.
- SwiftUI-интерфейс в стилистике iOS, светлая и тёмная темы.
- Облачный AI внутри приложения, запуск сразу после сборки без ручной настройки.
- Зависимости — только Swift Package Manager, без CocoaPods.
- Несколько сохраняемых чатов и восстановление истории после перезапуска.
- Остановка генерации, загрузка, пустой экран, понятные ошибки и повтор запроса.

## Уточнения, появившиеся по ходу работы

- Русская и английская локализации с ручным выбором языка в настройках.
- Выдвижная панель слева со списком диалогов.
- Закрытие клавиатуры при касании вне поля ввода.
- Создание, переименование, закрепление и удаление чатов.
- Короткие автоматические названия и корректное отображение длинного заголовка.
- Нативное форматирование Markdown: заголовки, списки, выделение и таблицы без отображения исходных маркеров.
- Большой экран настроек с темой, языком, звуками, уведомлениями и кнопкой «Оценить приложение».
- Одноразовое знакомство с приложением и стартовый экран загрузки около одной секунды.
- Вложения из фотогалереи и файлов; анализ изображений и извлечение текста документов.
- Ответ должен появляться целиком после завершения генерации, а не частями.
- Устранение зависаний при прокрутке во время запроса и при добавлении изображения.
- Только один активный AI-запрос на всё приложение. В остальных чатах ввод блокируется и показывается локализованное сообщение «Ожидайте…».
- Отдельные сообщения для отсутствия сети, таймаута, запрета доступа, исчерпания запросов и превышения лимита токенов.

## Критерий готовности

Проект собирается двойным кликом по `Build.command`, запускается в iOS Simulator, сохраняет диалоги, отправляет запросы в Groq и корректно обрабатывает основные пользовательские и сетевые состояния.
