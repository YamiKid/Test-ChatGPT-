# Проверка проекта

## Автоматическая проверка сборки

```sh
./Build.command
```

Скрипт собирает отладочную версию для iOS Simulator в `.build/DerivedData`. Если Simulator уже запущен, приложение дополнительно устанавливается и открывается автоматически.

## Что проверялось вручную

- Первый запуск, одноразовое знакомство с приложением и повторный запуск без него.
- Создание, выбор, переименование, закрепление и удаление диалогов.
- Сохранение чатов после перезапуска.
- Русский и английский интерфейс, ручной выбор языка.
- Светлая, тёмная и системная темы, включая экран настроек.
- Отправка обычного текста и показ готового ответа целиком.
- Остановка запроса и повторная отправка после ошибки.
- Блокировка ввода в других чатах во время активного ответа.
- Прокрутка длинного ответа и прокрутка во время запроса без роста CPU до бесконечного цикла.
- Выбор фотографии, уменьшенный предварительный просмотр и отправка изображения.
- Выбор PDF и текстовых файлов, извлечение и отправка их содержимого.
- Отображение заголовков, списков, выделения и таблиц в ответах.
- Сборка и запуск на iPhone 17 Pro Simulator с runtime iOS 26.5.

## Последняя проверенная команда

```sh
xcodebuild -project Chat.xcodeproj -scheme Chat \
  -sdk iphonesimulator -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```
