Да. Сейчас приложение использует бесплатный anonymous‑endpoint Pollinations и модель `openai-fast`, которая фактически соответствует текстовой `GPT‑OSS 20B`.

Основные ограничения:

- Контекст модели — теоретически до 131 072 токенов. Но Pollinations может устанавливать собственный меньший практический предел. [Характеристики GPT‑OSS 20B](https://developers.openai.com/api/docs/models/gpt-oss-20b).
- Приложение само передаёт только последние 30 сообщений каждого чата. Это не 30 запросов — старые сообщения просто перестают попадать в контекст AI.
- Точный максимальный размер одного ответа для anonymous‑endpoint публично не зафиксирован. Сейчас `max_tokens` не задаётся, поэтому используется лимит сервера.
- Для anonymous‑режима ориентировочное ограничение — один одновременный запрос с интервалом около 6 секунд. При нескольких чатах Pollinations может поставить запросы в очередь или вернуть `429`. Эти цифры могут меняться. [Данные из официального репозитория Pollinations](https://github.com/pollinations/pollinations/issues/4817).
- В приложении установлен таймаут 60 секунд. Если сервер отвечает дольше, появится ошибка с возможностью повторить.
- Возможны ответы `429` — слишком много запросов, `503` — временная перегрузка и `502` — проблема вышестоящего провайдера.
- `openai-fast` принимает только текст. Изображения сейчас предварительно анализируются на устройстве через Apple Vision, после чего текстовое описание отправляется модели. [Текущий каталог anonymous‑моделей](https://text.pollinations.ai/models).
- Бесплатный anonymous‑доступ не имеет гарантированного SLA: модель, скорость и лимиты могут измениться.

Для снятия ограничений нужен серверный `sk_`‑ключ: Pollinations не устанавливает для него собственный фиксированный rate limit, но расходуется баланс Pollen и остаются ограничения внешнего провайдера. Такой ключ нельзя безопасно хранить внутри iOS-приложения — даже обфускация не защищает его. Для мобильного приложения Pollinations рекомендует авторизацию BYOP/OAuth либо собственный backend. [Официальная документация](https://github.com/pollinations/pollinations/blob/main/gen.pollinations.ai/src/docs/apidocs-recipes.md).
