# AI logs

В этой папке находится очищенный экспорт истории работы с Codex за день разработки:

- `codex-session.md` — сообщения пользователя и ответы Codex в удобном для чтения виде.

Исходные файлы сессий Codex намеренно не копировались: кроме диалога они содержат системные инструкции, внутренние рассуждения, полные результаты команд, локальные пути, идентификаторы устройств и введённый во время разработки API-ключ.

При экспорте удалены системные сообщения, инструкции разработчика, внутренние рассуждения, результаты инструментов, идентификаторы сессий и точное время сообщений. API-ключи, адреса электронной почты, локальные пути, домашнее имя пользователя, UUID устройств и аппаратные идентификаторы удалены либо заменены маркерами `[СКРЫТО_*]`. Смысл пользовательских запросов и ответов AI сохранён.
